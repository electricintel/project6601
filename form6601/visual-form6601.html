Visual Form 6601

A clean, visual representation of the Form 6601 declaration.

Declaration Overview

Form 6601 is a burden-neutral, classification-clean declaration of value. It avoids exploitative categories and focuses on human-centered fairness.

The Five Value Streams
Creation Value
New value produced by the individual or cooperative.
Exchange Value
Value received through trade, barter, or mutual exchange.
Growth Value
Value gained through improvement, development, or expansion.
Transfer Value
Value moved between parties without exploitation.
Autonomous Value
Value generated independently without external classification.
Declaration Fields
  • Declarer Name
  • Declarer Type (Individual / Cooperative)
  • Value Stream Selection
  • Description of Value
  • Burden-Neutral Statement
  • Classification-Clean Statement
  • Date of Declaration
